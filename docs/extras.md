<h1 align="center">Extra Features</h1>

Optional features are disabled in standard builds. Enable them under `extraFeatures` in `build.options.json`, then [rebuild](building.md).

## README support

Set `readmeSupport` to `true` to display a directory's `README.md` above its listing. Markdown and HTML are rendered with [Parsedown](https://github.com/erusev/parsedown); only enable this for README files you trust.
